# 晶选 · 黑卡升级状态

## 已完成

- 首页共用同一内容池，支持双列瀑布流与大尺寸金属黑卡两种模式；浏览偏好可切换并保存到 Supabase，未登录时本地保存。黑卡正反面共用 3:4 容器，翻开后保留尺寸，详情才连续展开。
- 详情展示实际文章全文和评论；收藏、点赞、阅读历史、用户发布内容、偏好及个人资料均连接到云端。发现页直接展示公开图文。
- 五位置导航保留中央发布动作，消息入口显示真实未读数量。支持搜索用户、唯一双人会话、实时文本及私有图片消息、历史分页、失败重试、复制、删除自己的消息、拉黑、举报及私聊权限。
- Supabase 已应用仓库中的初始化及增量迁移，现有 80 篇独立示例文章以稳定 ID 导入，标记为演示内容。原项目在迁移前没有 public 表或用户数据。
- 消息读写由数据库 RLS 和带权限检查的 RPC 控制。图片 Bucket 为私有，5 MB 限制，仅会话参与者可读取。举报保留消息证据，管理员可通过受限 API 处理。
- Vercel 项目已设置正确 Supabase URL 与公开 anon key；服务端密钥未加入前端或 Vercel 配置。

## 已验证

- 使用三个独立测试账号验证唯一会话、消息幂等重试、陌生用户无法读取或发送私聊、拉黑与接收权限、未读游标、图片读取权限、角色提权拦截及内容状态隔离。
- 两个浏览器会话验证消息实时送达、未读角标增加、打开会话后的已读清零。
- TypeScript 检查与 Next.js 生产构建通过。生产模式下，320 / 375 / 430px 视口均验证翻卡正反面尺寸一致、进入详情及返回正常。
- 测试后已删除三个 QA 账号、会话与私有图片，数据库保留 80 篇演示文章。

## 当前边界

- 80 篇演示文章使用现有固定图片资源，图片种类少于文章数量；外部图源失败时显示回退样式。
- 浏览器通知在页面运行且已获授权时可提示新私聊；尚无关闭网页后的系统推送。
- 候选内容接口单次最多读取 1000 条，前端分批渲染。大规模正式内容接入后应改为服务端游标分页。
- 演示评论与真实用户评论按数据来源区分；管理员举报处理目前只有受限 API，没有独立后台界面。
- 移动端采用模拟视口验证，尚无实体设备的键盘、性能和弱网报告。
