# Lucide icon attribution

- Source: Lucide Icons, https://lucide.dev/icons
- Repository: https://github.com/lucide-icons/lucide
- License: ISC; see `LUCIDE-LICENSE.txt`.
- Assets: selected Lucide official SVG files were converted to local Android VectorDrawable XML resources named `ic_lucide_*.xml`.
- Filled interaction-state assets (`star_filled`, `like_filled`, `save_filled`) are local state variants based on the official Lucide `star`, `heart`, and `bookmark` outlines. Lucide upstream SVGs are outline icons; the app's local variants apply solid fill for the selected state.
- Legacy IconPark resources are retained for rollback and for semantics without a confirmed Lucide match.
